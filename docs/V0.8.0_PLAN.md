## Part 1: GitHub Action Hardening & Usability

### Audited Bug Fixes
- **Sanitize Annotation Outputs (`action.yml`)**: Escape `::` markers, `\r`, `\n` in `github-script` before calling `core.error()`, preventing workflow command injection from untrusted SQL.
- **Redact Secret Credentials (`action.yml`)**: Add regex scrubbing to `safe-migrate-diagnostics.log` to prevent `DATABASE_URL` and `SAFE_MIGRATE_CACHE_KEY` from leaking in build artifacts.
- **Isolate Cache Keys by Target Branch (`action.yml`)**: Scope `cache_prefix` using `${GITHUB_BASE_REF:-${GITHUB_REF_NAME}}` to stop cross-branch baseline cache pollution.
- **POSIX Shell Compatibility (`scripts/action-baseline`)**: Fix unquoted shell parameter expansions and replace Bash process substitution (`> >(...)`) with POSIX-compliant redirects.
- **Smart Path Fallback (`action.yml`)**: Default `path` input to `migrations` if directory exists, offering actionable diagnostics on missing paths.

### Action Guide Rewrite (`docs/GITHUB_ACTIONS.md`)
- **2-Minute Quickstart**: Provide copy-paste workflow snippets for PR linting and trusted branch baseline refresh.
- **Visual Baseline Flow**: Add ascii diagrams clarifying cache save/restore cycles.
- **Security Section**: Document why PR authors cannot modify `.toml` configs to bypass lint rules, showing the trusted base checkout pattern.

## Part 2: Core Engine Architecture (~4% Completion)

### 1. Directed Role Graph & Transitive Privilege Solver
- **Model Upgrade (`src/model/role.rs`)**: Store explicit `RoleGrantEdge` instances on `RoleState`:
  ```rust
  pub struct RoleGrantEdge {
      pub target_role: ObjectId,
      pub grantor: ObjectId,
      pub admin: bool,
      pub inherit: bool,
      pub set: bool,
  }
  ```
- **State Applicator (`src/analysis/state/apply_role.rs`)**: Process `INHERIT`, `SET`, and `ADMIN` options with exact PostgreSQL default rules (unspecified `INHERIT` defaults to member's `inherits` attribute; `SET` defaults to true; `ADMIN` defaults to false).
- **Transitive Solver (`src/analysis/state.rs`)**: Evaluate relation privileges through path-wise BFS reachability where every edge in the path requires `inherit: true` and member `ROLINHERIT`. Enforce `SET ROLE` path rules.

### 2. Version-Gated `NOT NULL` Sourcing (PostgreSQL 18)
- **Catalog Query (`src/sync.rs`)**: Version-gate column nullability:
  - PG 14–17: Read `attnotnull` from `pg_attribute`.
  - PG 18+: Query `pg_constraint` where `contype = 'n'` and join `refobjsubid` to source columns.
- **Model & Graph (`src/model/constraint.rs`, `src/analysis/graph.rs`)**: Support `ConstraintKind::NotNull` and update `ALTER TABLE ... DROP CONSTRAINT` to clear column nullability cleanly.
